# Declaración de uso de IA

## Herramienta utilizada

Se utilizó ChatGPT como herramienta de apoyo durante el desarrollo del módulo Micro-HIS Citas Médicas y Agenda.

## Propósito del uso

La herramienta fue utilizada para:

- Revisar la organización arquitectónica del proyecto.
- Analizar la separación por capas.
- Apoyar en la creación inicial de estructuras de código.
- Revisar comandos Git y validaciones técnicas.
- Apoyar en la elaboración de documentación.

## Aplicación de las sugerencias

Las recomendaciones fueron revisadas y adaptadas al contexto del proyecto.

El desarrollo final mantiene:

- PHP 8.2+ sin framework.
- Patrón Repository.
- PDO con sentencias preparadas.
- SQLite como almacenamiento.
- Reglas propias del dominio de citas médicas.

## Validación humana

Todo el código fue ejecutado y revisado mediante:

- Validación de sintaxis PHP.
- Ejecución de pruebas automatizadas.
- Validación de persistencia.
- Revisión del historial Git.

La decisión final sobre arquitectura, implementación y cambios pertenece al estudiante.
