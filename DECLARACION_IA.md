# Declaración de uso de IA

## Herramienta utilizada

Se utilizó ChatGPT como herramienta de apoyo durante el desarrollo del módulo Micro-HIS Citas médicas y agenda.

## Propósito del uso

La herramienta fue utilizada para:

- Revisar la organización por capas del proyecto.
- Analizar la separación entre Domain, Application, Persistence y Presentation.
- Apoyar en la generación de estructuras iniciales de código.
- Revisar comandos Git y validaciones técnicas.

## Partes aceptadas y modificadas

Las sugerencias relacionadas con arquitectura y estructura fueron revisadas y adaptadas al contexto del módulo asignado.

Se modificaron elementos del código para mantener:

- PHP 8.2+ sin framework.
- PDO con sentencias preparadas.
- Reglas propias del dominio de citas médicas.
- Datos ficticios para pruebas.

## Validación humana

Todo el código fue ejecutado, revisado y validado manualmente mediante:

- Verificación de sintaxis PHP.
- Pruebas automatizadas.
- Validación de persistencia SQLite.
- Revisión del historial Git.

La decisión final sobre arquitectura, implementación y cambios pertenece al estudiante.
